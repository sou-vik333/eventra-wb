# Eventra WB

Eventra WB is a West Bengal-focused AI-powered event management,
service discovery, comparison and booking platform.

## Project Status

Development in progress.

## Technology Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL
- Prisma
- Pinecone
- AI/LLM API
- Cloudinary
- Razorpay

## Project Structure

- client — Frontend application
- server — Backend application
- prisma — Database schema and migrations
- docs — Project documentation
